NATIVE PEPECOIN · MAINNET
Public-peer synchronization
This app indexes blocks from public peers without Core RPC or a local node. It is not a fully validating Core node. Chain reorganizations stop indexing for a safe rescan.
For historical imports or a damaged index: stop the running server, then run npm run rescan. This starts a new index and preserves the previous one. Withdrawals remain paused until it catches up.
